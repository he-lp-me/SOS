SOS | 머신러닝 기반 상품 할인 시점 예측 시스템
언제 구매해야 가장 합리적일까?
상품의 가격 변동 데이터를 분석하고, 머신러닝·시계열 예측을 활용해 향후 할인 가능 시점과 예상 할인율을 제공하는 프로젝트입니다.

프로젝트 유형: AI/ML 기반 가격 예측 서비스 · 팀 프로젝트

1. 프로젝트 개요
온라인 상품 가격은 시점에 따라 달라지지만, 사용자가 구매 전 적절한 할인 시점을 예측하기는 어렵습니다. 기존의 가격 조회 방식에서 나아가, 과거 가격 흐름을 토대로 미래 구매 시점을 판단하는 데 도움을 주는 서비스를 목표로 했습니다.

해결하려는 문제
- 현재 가격만으로는 향후 가격 변동과 할인 가능성을 판단하기 어렵다는 점
- 상품별 가격 이력에서 반복되는 패턴과 시계열 변화를 함께 고려해야 한다는 점
- 예측 결과를 사용자에게 이해하기 쉬운 구매 판단 정보로 제공해야 한다는 점
- 
핵심 접근 방식
1. 가격 데이터 분석: 상품별 가격 이력에서 시계열 패턴 및 예측에 활용할 특성을 분석
2. 할인 가능성 예측: LightGBM 기반의 머신러닝 접근
3. 가격 흐름 예측: NHITS 기반의 시계열 딥러닝 접근
4. 결과 제공: 예상 할인 시점과 할인율을 구매 의사결정에 활용할 수 있도록 구성

2. 기술 스택
구분	기술	활용 목적
ML	Python, LightGBM	가격·할인 관련 특성 기반 예측 모델링
Time Series DL	NHITS	가격 변화의 시계열 패턴 학습 및 미래 값 예측
Backend	Django 4.2, Django REST Framework	서버 및 API 개발 기반
Frontend	React 19, JavaScript	웹 사용자 인터페이스 개발 기반
Database	SQLite (현재 공개 코드 설정)	로컬 개발 환경 데이터베이스
Experiment / Infra	AWS EC2, GCP GPU 환경	서버 환경 구성 및 모델 실험 경험

3. 예측 모델 설계 및 개발
3.1 LightGBM — 할인 관련 패턴 예측
- 상품 가격 이력에서 예측에 필요한 특성을 도출하는 피처 엔지니어링 수행
- 가격 변화 및 시간 흐름을 고려한 입력 변수 구성
- LightGBM을 사용해 할인과 관련된 예측 문제에 접근
- 모델 결과가 실제 구매 판단에 활용될 수 있도록 출력 형태 검토
3.2 NHITS — 미래 가격 흐름 예측
- 시간 순서에 따른 가격 변동을 학습하는 시계열 예측 방식 적용
- 과거 시점의 가격 데이터로 향후 변화를 추정하는 모델링 진행
- 머신러닝 모델과 시계열 모델의 역할을 구분해 예측 방식 설계
3.3 사용자 중심의 예측 결과
단일한 예측값만 제시하기보다 10%·50%·90% 수준의 예측 정보를 활용해 사용자가 할인 시점을 비교할 수 있도록 하는 방향을 검토했습니다. 정확한 수치의 의미(분위수/확률/구간)와 산출 방식은 실험 결과 자료를 추가할 때 명시할 예정입니다.
평가 지표, 데이터 규모, 실험 조건 및 실제 성능 수치는 검증된 실험 결과를 확인한 뒤 추가합니다.

4. 본인 기여 및 문제 해결
주요 기여 분야: 데이터 분석 · ML/시계열 모델링 · 개발 환경 구성
- 문제 정의: 단순 가격 조회를 넘어 미래 할인 가능 시점과 할인율을 추정하는 예측 문제로 구체화
- 모델링: LightGBM 및 NHITS를 활용해 구조화된 특성 기반 접근과 시계열 접근을 함께 검토
- 피처 엔지니어링: 가격 변화 데이터의 특성을 고려한 입력 변수 분석과 모델 성능 개선 시도
- 개발 환경: AWS EC2 및 GCP GPU 환경을 다루며 서비스·모델 실험에 필요한 인프라 구성 경험 축적
기술적으로 고민한 부분
서로 다른 모델이 담당하는 예측 문제를 어떻게 연결할 것인가?
LightGBM의 특성 기반 예측과 NHITS의 시계열 예측을 구분하고, 최종적으로 사용자가 이해할 수 있는 할인 시점·예상 할인율 정보로 연결하는 방법을 고민했습니다.

예측 결과를 어떻게 해석 가능한 정보로 전달할 것인가?
사용자에게 단일 예측값을 정답처럼 전달하기보다 복수의 예측 수준을 제공하는 방식을 검토했습니다. 예측 구간의 정의와 신뢰성을 명확하게 설명하는 것이 중요하다는 점을 확인했습니다.
팀 프로젝트이므로 본인 담당 범위, 팀원과 공동 작업한 범위, 실험 결과에 대한 근거 자료를 최종 제출 전 구체적으로 보완할 예정입니다.

5. 회고 및 개선 방향
이번 프로젝트에서는 가격 데이터를 사용자의 구매 의사결정을 돕는 예측 정보로 바꾸는 과정을 경험했습니다. 모델 성능 자체뿐 아니라 데이터 특성을 해석하고, 서로 다른 예측 방법을 연결하고, 결과를 사용자가 이해할 수 있는 방식으로 전달하는 것이 중요하다는 점을 배웠습니다.

앞으로는 실험 재현성을 높일 수 있도록 데이터 분할 기준, 평가 지표, 주요 하이퍼파라미터 및 모델 코드를 공개 가능한 범위에서 정리하고, 서비스와의 연결 과정을 문서화할 계획입니다.
